# Cao v2.4 foundation compiler

**Research date:** 2026-09-10
**Status:** full 0–540 Ma package promoted and source-artifact verified; the joined application build and local acceptance checks pass; see the adoption record for exact results.

## Scope and bounds

The first application foundation uses only the pinned [Cao et al. 2024](https://doi.org/10.1016/j.gsf.2024.101922) model release [2.4](https://doi.org/10.5281/zenodo.13628813), CC BY 4.0, retrieved 2026-09-09. It covers the application domain 0–540 Ma at 109 five-million-year display checkpoints while retaining finer source rotation knots. It does not ingest PALEOMAP, ETOPO, Beck or another model.

Before generation, `reconstruction-cao-foundation-v1/policy.json` established a 64 MiB external staging limit, a 4 GiB source-store limit and a 50 MiB eventual public-foundation limit. The reconstruction compiler owns generated candidate files; the reconstruction program deletes the external candidate after accepted promotion or supersession. The first stage was restricted to source cataloguing, counts and size projections. It forbade bulk geometry before the runtime and renderer schemas froze, rejects source digest changes, and preserves unknown surface, crust, ownership and seam states. External captures created by the integration program share the parent stage and count toward its 64 MiB limit.

## Pinned source inventory

[`inventory_cao_foundation.py`](../../scripts/research/inventory_cao_foundation.py) validates eight source members: three boundary-era GPML files, `TopologyBuildingBlocks.gpml`, `1000_0_rotfile.rot`, `shapes_continents.gpmlz`, `shapes_coasts.gpmlz`, and `static_polygons.gpmlz`. The durable compact result remains external at `reconstruction-cao-foundation-v1/source-inventory.json`; it contains hashes, byte sizes, feature/type counts, geometry counts, plate counts, validity endpoints and the projection, but no runtime arrays.

The sources contain 341,762 geometry points across those seven geometry collections and 641 distinct geometry plate IDs. The rotation file contains 5,942 finite-rotation records for 1,184 moving plate IDs and 428 distinct source knot ages within 0–540 Ma. Feature validity intersects the 109 display ages 331,341 times. A canonical six-byte quantized direction for every source point would occupy about 2.05 MB before ring, triangle and metadata overhead. The validity incidences alone would require at least 5.30 MB with a hypothetical sixteen-byte feature-slot record. Canonical geometry plus shared motion is therefore the selected representation; source geometry is not duplicated at every age.

These collections have distinct meanings. `static_polygons.gpmlz` supplies reconstructable plate/fragment geometry and ownership, not exposed land. `shapes_continents.gpmlz` contains a mixture of `ClosedContinentalBoundary`, `UnclassifiedFeature`, `IslandArc`, `TerraneBoundary`, `Craton`, `ContinentalFragment`, `Coastline` and other types. `shapes_coasts.gpmlz` contains model-derived source geometry. None is silently promoted to observed palaeoshoreline, definitive crust type or dated exposure. The exporter retains collection, feature type, source feature ID, plate ID and validity; unsupported surface and crust classification remains `unknown`.

## Runtime package v2 contract

The coordinated manifest contains package/frame identity, the 0–540 Ma domain, a core asset, one motion-palette catalog/binary pair, and 109 age-qualified checkpoint assets. The palette binary has a 32-byte little-endian `EHMP` version-2 header followed by global `{u32 ageMicroMa, f32 w, x, y, z}` records. Catalog entries identify plate ID, reference age, valid motion interval, disjoint sample offset/count, source IDs and exact source intervals. Samples are sorted, include exact endpoints and every qualified source knot, and use strict rotations without identity fallback.

Rigid material charts bind `{paletteId, entryId}`. Multiple charts can share one palette entry; material identity, lifecycle, source features and surface evidence remain chart-side. Numerical sample domain and material lifecycle are separate. A GPML geometry can be stored at virtual-present 0 Ma while its feature is inactive there, so the palette reference age may lie outside the chart lifecycle. The compiler normalizes every stored quaternion into the transform from the chart's declared stored-coordinate basis to the requested frame; the runtime applies that quaternion directly. A supported-reference entry stores precomputed `q(age) × inverse(q(reference))`; an absolute virtual-origin entry would store strict native total `q(age)`. Identity fallback never establishes support. The inventory validates source feature `GPlates-9f445a60-4cda-4bb8-9559-026132c268de`: its geometry import time is 0 Ma, its validity is 1100–400 Ma, and direct total rotation at 450 Ma reproduces native pyGPlates reconstruction below `1e-12` radians. A separate source-wide probe found no Cao geometry plate with strict `q(0)` absent but a strict ancient total rotation present at sampled 0–540 Ma ages; plate 30202 has neither and remains unsupported rather than serving as a virtual-origin witness. Checkpoints carry age-qualified geometry/control state and never duplicate motion fractions.

## Geometry and timing boundary

Canonical source polygons are stored once in model-qualified material charts and posed by shared motion entries where rigid support is valid. Resolved topology and directed boundary state belongs to exact display checkpoints. Feature validity endpoints and rotation knots are source/event evidence; five-million-year display cadence is not treated as event time. Unsupported source-file seams, split/merge ambiguity, missing strict circuits and ownership disagreement remain explicit states rather than fixed geometry.

The first staged render candidate uses only `shapes_coasts.gpmlz`, avoiding redundant export of all three overlapping geometry collections. [`compile_cao_foundation.py`](../../scripts/research/compile_cao_foundation.py) exports source rings to unit XYZ and [`triangulate_cao_rings.mjs`](../../scripts/research/triangulate_cao_rings.mjs) applies Three.js Earcut through a local gnomonic projection, which preserves source great-circle edges as straight projected edges. The verifier checks projection domain, non-degenerate spherical triangles, triangle-centroid containment, holes and spherical-area residual. Of 2,938 polygon parts, 2,921 pass. Twelve Australian/Hokkaido/Antarctic regional parts retain degenerate-triangle status, three overlapping Australian units fail area residual, and two near-zero-area three-point source rings produce no triangulation. Their exact source rings remain available as line evidence; fill is explicitly unavailable rather than repaired. The accepted candidate has 102,217 source vertices and 71,119 source triangles. Its unrefined direction, index and metadata files are each below the 8 MiB artifact cap. Neutral physical height is explicitly unknown display synthesis at a 6,371,008.8 m radius/zero sea-level datum.

The approved display refinement bounds every derived geodesic edge to 1°. [`project_cao_triangle_refinement.py`](../../scripts/research/project_cao_triangle_refinement.py) projects 174,775 vertices and 213,117 triangles, about 2.10 MB of float32 XYZ plus 2.56 MB of uint32 indices. The actual worst planar triangle sinks 305.003 m below the sphere; float32 direction norm contributes 0.304 m. A 400 m render-only shell separation therefore retains 94.69 m margin. It participates in bounds and picking, is excluded from physical height and vertical exaggeration, and carries no topographic claim.

A uniform-draw fallback grouped by motion entry, exact lifecycle and source material class would require 566 active groups at 0 Ma, 294 at 450 Ma and 288 at 470 Ma; 566 is the maximum across the 109 ages. Those counts ruled out one draw per source part or lifecycle group. The foundation therefore uses one packed global land batch with per-vertex palette/chart indices and per-triangle chart lookup. Spatial LOD subdivision was not implemented in this foundation.

The existing seven-age tectonic diagnostic independently exposed 79 cases where point containment and pyGPlates native sharing-side ownership disagree. Those records remain unavailable. Its mixed-shape membership field is descriptive only. Global ocean cohort birth, seafloor age, detailed relief and calibrated climate are deferred foundation fields and must retain unknown or model-synthesis status until separately qualified.

## Promotion gates

The staged package passed digest mutation, strict-circuit, lifecycle, triangle ownership, CPU/pyGPlates motion-oracle and renderer seam checks before full promotion. Superseded runtime assets and their production generators were removed after the Cao-only App and renderer stopped consuming them. Commit, push and release remain separate actions.

The initial two-age, twelve-patch integration package (779,021 bytes) was superseded after it proved the real loader/renderer path. The current `public/data/reconstruction/cao-v2.4/manifest.json` is the full 109-checkpoint package described below. Every checkpoint uses uniform physical height zero. The separate 400 m shell separation remains renderer-only.

The external full candidate now contains 2,772 model-geography charts, 139,152 vertices, 198,110 triangles, 2,833 locally qualified palette intervals, 207,417 motion samples and 109 uniform-height checkpoints. Missing circuits or interpolation discontinuities split palette support locally; they do not discard an otherwise usable feature lifetime. Of 2,921 triangulated source parts, 149 have no qualified motion interval and the 17 triangulation failures remain line-only. The compiler records every omission and representative missing ages in `compiler-coverage.json` outside the repository.

Every checkpoint carries an exact native Cao boundary and topology-ownership layer. The 109 EHNB layers total 7.47 MB and the 109 EHTO layers total 2.97 MB. Boundary payloads retain directed f32 unit XYZ, offsets, source feature/type, polarity and ordered adjacent plate IDs; tangent and left normal are derived from adjacent directions and are not duplicated. Exact topology polygons retain exterior/hole roles and answer sparse instantaneous ownership as owner, ambiguous or unknown. They do not create persistent ocean material or seafloor age. Full diagnostic velocity vectors remain offline.

The one-time Natural Earth 1:110m country reference is partitioned against Cao static polygons at 0 Ma and shares the same motion palette. Every accepted one-degree segment has matching endpoint and midpoint ownership and inherits the matched source fragment's validity. It contains 970 country/fragment charts and 9,602 line segments; 2,443 subdivided segments (20.28%) without consistent supported static-fragment ownership are omitted and recorded, never assigned a country-wide default plate. It is a modern locator overlay, not historical-border evidence.

Seven of the eight coordinate-bearing application POIs bind uniquely to Cao static fragments and share existing palette motion. Cairo fossil forest remains unsupported because its uniquely containing source fragment uses plate 10106, for which the model supplies no strict motion circuit in the requested interval. The anchor is omitted instead of borrowing a neighbouring plate. Every supported anchor retains its source event interval and coordinate uncertainty.

The complete external candidate included compiler diagnostics that are not runtime inputs. Its final transitive public artifact set is 27,849,813 bytes across 552 files; the nested manifest digest is `7611a27b912e96f0c1a052a87f6b836a52bbb855da0095d7da37816b37b92cdc`. Every artifact remains below 8 MiB. A post-promotion audit found exactly those 552 files, no unlisted nested asset, and matching byte count and SHA-256 for every root-manifest output. The 552 identical external runtime copies (27,849,813 bytes) were then deleted; compact compiler diagnostics remain within the owned 64 MiB external allocation. Production manifest/core/checkpoint/anchor validators and packed EHMP/EHGB/EHGL/EHNB/EHTO decoders accept the package. Deliberate palette, surface geometry, country-line and native-layer header mutations fail through those same decoders. Repeating the source clock is avoided through shared interval sets.
